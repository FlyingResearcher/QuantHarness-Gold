上周有个做黄金期货的朋友找我吐槽，说每天早上打开交易软件，面对 COMEX 和 SHFE 的 K 线图，堆在屏幕上的 RSI、MACD、布林带……看得头晕，但真正的交易决策还是凭感觉。

我特别懂这种感觉。技术分析指标越来越多，图表越画越花，但没有一个东西帮你把这堆指标、形态、趋势合成一个可以落地的判断。

最近我一直在折腾一个开源项目，刚好就是解决这个问题的。它叫 QuantHarness Gold——基于 Y-Research-SBU 那篇备受关注的 QuantHarness 论文架构，做了一个黄金市场的专属实现。

01

先说说它从哪来

2025 年 9 月，Fei Xiong、Xiang Zhang 等五位研究者发表了一篇 arXiv 论文——QuantHarness: Price-Driven Multi-Agent LLMs for High-Frequency Trading。

这篇论文提出了一个很有意思的想法：不是让一个大模型从零分析市场，而是让多个"小专家"Agent 各干各的，然后汇总成交易决策。他们用 LangGraph 把指标计算、图表形态识别、趋势分析拆成三个独立 Agent，再交给一个 Decision Agent 综合。这个架构在多品类上都跑出了不错的效果。

QuantHarness Gold 就是站在这篇论文肩膀上的一个工程实现。原团队验证了"多 Agent 协同做市场分析"这条路走得通，那我就想，能不能把这套架构在单一品类上做深、做实用？选了黄金，因为它兼具商品、避险、货币三重属性，技术分析的密度和难度都够高。

在这里特别感谢原 QuantHarness 研究团队——如果不是他们把这套架构跑通了、把论文公开了，就不会有这个项目。感谢 Fei Xiong、Xiang Zhang、Aosong Feng、Siqi Sun、Chenyu You 五位作者。

02

它做了什么事

一句话说透——让三个擅长不同事的 LLM Agent，像一个小团队一样协同工作，最终给你一个 LONG 或 SHORT 的方向判断。

从公开数据源拉取黄金 K 线，自动在东方财富、同花顺、AKShare 之间 Failover。然后分三路并行分析，最后汇总成一份结构化的 JSON 决策。

图：三个专业 Agent 并行分析后由 Decision Agent 综合

Indicator Agent 负责技术指标——RSI、MACD、Stochastic、ROC、Williams %R。

Pattern Agent 负责看图——先生成 K 线图，再用视觉 LLM 识别形态。

Trend Agent 负责趋势——拟合支撑位和阻力位，判断当前在通道里还是正在突破。

三份报告交给 Decision Agent 综合，输出包含方向、风险回报比、预测周期、具体理由的交易决策。

03

相比原版，我加了什么

原版 QuantHarness 是研究论文，这个项目是它的黄金落地版。做了几个方向的延伸：

第一，把数据源做成了多源自动 Failover。论文里用的数据是研究场景的，这里接了东方财富、同花顺、AKShare 三个公开源，哪个挂了自动换下一个，还做了 OHLC 完整性校验。COMEX 美盘和 SHFE 沪金主力合约都覆盖。

第二，加了双槽位 LLM 配置。原版假设一个模型干所有事，这里允许给指标分析配个便宜的文本模型，给形态识别配个带视觉能力的多模态模型，按实际需求组合成本和能力。

第三，完整的执行溯源。每一步是 LLM 算的还是本地程序算的，用了哪个模型，都记在 analysis_provenance 里。研究的时候最怕黑箱，这个设计就是为了让分析过程可追溯、可复现。

同时给了 CLI 和 Flask Web 界面两种用法。终端党一条命令出 Markdown 报告，喜欢图形界面的打开浏览器就能配置模型、选合约、看结果。

04

接下来要做什么

现在这个版本是研究起点，后面还有几块硬骨头想啃：

回测引擎。有了方向判断，但这个判断在历史上到底准不准？打算把每次 Decision Agent 输出的 JSON 决策存下来，跑历史回放，算胜率、盈亏比、最大回撤这些指标。论文里的实验结果要自己在黄金品类上复现一遍。

扩展到更多资产。现在只支持 COMEX 和 SHFE 黄金。后面想看看能不能把同样的多 Agent 架构跑在白银、原油、或者 A 股主要指数上——毕竟原版论文就是多品类的，黄金只是第一步。

更多 Agent 类型。现在只有指标、形态、趋势三个，原版论文里其实还探索了更多 Agent 组合。可能加一个宏观数据 Agent，把美元指数、实际利率、ETF 持仓这些外部因子拉进来做交叉验证。

感兴趣的朋友可以点个 star，后面更新我会在 GitHub 上持续同步。

最后说一句实在话

QuantHarness Gold 不是圣杯。AI 不会替你承担风险，也不会保证赚钱。但它把分散的技术分析这件事做得更结构化、更可追溯了——这是我觉得最有价值的地方。

真正有意思的不是"AI 帮你分析 K 线"，而是"多个 AI Agent 像一个小团队一样协同分析"——这件事在金融之外的很多场景里，都值得继续探索。

项目完全开源。如果你在研究黄金交易、做多 Agent 应用、或者就是对这个方向感兴趣，欢迎过来看看，提 Issue、发 PR 都欢迎。
